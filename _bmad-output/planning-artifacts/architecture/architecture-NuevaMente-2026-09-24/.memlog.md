- (decision) Modo de trabajo: coaching path — decisiones interactivas una por una
- (decision) Entregables: spine (build substrate) + documento de arquitectura completo para documentación del hackathon en GitHub
- (decision) AD-1 Paradigma: Pipeline con separación modular. LangGraph orquesta el flujo (grafo de nodos), pero cada nodo delega a módulos de dominio independientes del framework. Binds: todo el sistema. Prevents: lógica de negocio acoplada a LangGraph, nodos gordos imposibles de testear en aislamiento.
- (decision) AD-2 Topología del grafo: pipeline lineal con edge condicional. START → ingest → retrieve → draft → review →[score≥0.7]→ format_output → END, con loop review→draft (max 1 reintento) cuando score<0.7. Sin supervisor — el flujo es determinista. Binds: FR-7,FR-8,FR-9. Prevents: overhead de supervisor LLM innecesario, latencia extra en 1GB RAM.
- (constraint) LLM confirmado: Gemini 3.5 Flash Lite (free tier más generoso: 15 RPM, 250K TPM, 500 RPD). Reemplaza la referencia genérica a 'Gemini Flash' del PRD. Las llamadas al LLM deben minimizarse por el rate limit de 15 RPM.
- (version) Gemini 3.5 Flash Lite: context window 1M tokens input, 65K tokens output. Verificado en web 2026-09-24.
- (decision) AD-3 Estrategia RAG: fast-path + stratified full-coverage retrieval. Fast-path: doc ≤ umbral de tokens (~50K) → todos los chunks directo al Redactor. Full-coverage: doc > umbral → (1) section map sin LLM (parsing estructura del texto), (2) 1 llamada LLM para query synthesis desde el mapa completo condicionada por perfil/formato/nicho, (3) FAISS retrieval con piso de cobertura por sección (fuerza inclusión mínima por sección sin representación), (4) budget de chunks proporcional por sección. Binds: FR-7, Open Question 1. Prevents: pérdida de contenido en documentos largos, sesgo hacia el inicio del documento.
- (constraint) Infraestructura: 1GB RAM + 1 OCPU + 4-8GB swap en OCI Always Free. El swap permite que procesos que excedan la RAM no mueran por OOM — probado con raggraph. Ajustar NFR-1 del PRD: el techo real de memoria usable es ~5-9GB (RAM+swap), no 1GB; el rendimiento degrada con swap pero no crashea.
- (direction) raggraph es referencia de stack probado (LangGraph+FAISS+VoyageAI+FastAPI corriendo en OCI 1GB), no modelo arquitectónico. NuevaMente debe ser significativamente más sofisticado en diseño, estructura de código y calidad de output.
- (decision) AD-4 Estado del grafo (NuevaMenteState): TypedDict con campos agrupados en Input (document_id, raw_text, file_name, perfil, formato, nicho), Pipeline (chunks, section_map, retrieved_chunks, generated_content), Control (review_result, retry_count), Output (educational_package, oci_upload_status). Sin messages — no es chatbot. FAISS no viaja en state — se accede desde módulo de infraestructura. Binds: todos los nodos del grafo. Prevents: nodos con side effects, estado implícito, acoplamiento entre nodos.
- (decision) AD-5 Módulos y dependencia: app/ (FastAPI, routers, static) → pipeline/ (LangGraph, state, nodos thin) → services/ (ingestion, rag, generation, storage) → infra/ (embeddings, vectorstore, llm, oci). core/ (schemas, models, exceptions) es transversal, importado por todos, no importa a nadie. Binds: todo el código. Prevents: lógica de negocio acoplada a framework, imports circulares, nodos imposibles de testear.
- (decision) AD-6 Structured output: el Redactor usa llm.with_structured_output(ModeloPydantic) para generar paquetes educativos tipados directamente. Cada formato pedagógico tiene su propio modelo Pydantic (FlashcardsPaquete, QuizPaquete, TutorialPaquete, ResumenEjecutivoPaquete, GuionClasePaquete) que hereda de PaqueteEducativoBase. El LLM devuelve instancias validadas, no texto libre. Fuente: documentación LangChain actualizada, patrón with_structured_output(). Binds: FR-8, FR-10, FR-11, services/generation.py, core/schemas.py. Prevents: parsing manual de JSON desde texto libre, errores de schema silenciosos, contenido que no cumple la estructura.
- (decision) AD-7 API async con polling: POST /api/v1/adaptar retorna HTTP 202 + task_id inmediatamente. GET /api/v1/adaptar/{task_id}/status retorna paso actual del pipeline + resultado final cuando completa. Pipeline corre en background (BackgroundTask o thread). La UI hace polling para mostrar progreso real por etapa. Task state se mantiene en memoria (dict in-process, concurrencia 1). Binds: FR-6, FR-14, FR-18. Prevents: bloqueo de Uvicorn worker durante 2 min, spinner genérico sin feedback, timeout de browser.
- (decision) AD-8 Persistencia FAISS: un directorio de índice por documento en data/faiss_indexes/{document_id}/. document_id = hash determinista del contenido del archivo. save_local/load_local de langchain-community. Si el documento ya fue indexado, se carga desde disco sin re-generar embeddings. Binds: FR-4, services/rag.py, infra/vectorstore.py. Prevents: colisión de índices entre documentos, re-embedding redundante, gasto innecesario de API Voyage AI.
- (decision) AD-9 OCI Object Storage: fire-and-forget post-entrega. Upload corre después de entregar resultado al usuario (no bloquea). Dos prefijos en bucket: sources/{document_id}/{filename} y packages/{document_id}/{perfil}-{formato}-{timestamp}.json. Fallo se loguea, no bloquea. Historial (FR-20) consulta list_objects(prefix=packages/) para armar barra lateral. Binds: FR-12, FR-13, FR-20, services/storage.py. Prevents: entrega bloqueada por fallo de OCI, pérdida de trazabilidad input→output.
- (decision) AD-10 Configuración: pydantic-settings (BaseSettings) en config.py. Todo configurable por env var. Defaults sensatos — funciona con solo API keys. Un solo punto de verdad. Incluye: llm_model, embedding_model, chunk_size, chunk_overlap, retriever_k, review_score_threshold, max_retries, fast_path_token_limit, oci_bucket_name, oci_namespace, faiss_index_dir. Binds: NFR-5, todos los módulos. Prevents: configuración dispersa, valores mágicos hardcodeados, credenciales en código.
- (decision) AD-11 Despliegue: Uvicorn directo (sin nginx) en OCI VM Always Free. systemd para persistencia. Swap 4-8GB obligatorio. FastAPI sirve static files + API. Servicios externos: Google AI API (Gemini 3.5 Flash Lite), Voyage AI API (voyage-4), OCI Object Storage. Cloudflare opcional — diferido a implementación. Binds: NFR-1, NFR-3. Prevents: complejidad de proxy innecesaria en v1, costos fuera de Always Free.
- (decision) AD-12 Convenciones: snake_case archivos, PascalCase modelos Pydantic, español para dominio / inglés para infra. IDs: UUID v4 para task_id, SHA-256 truncado 16 chars para document_id. Fechas ISO 8601 con tz. Errores JSON con status+codigo+mensaje en español. Logging structlog/stdlib a stdout con task_id+node_name+duration_ms. Env vars prefijadas NM_. Binds: todo el código. Prevents: inconsistencia de naming, IDs colisionables, errores sin contexto, config que colisiona con otras apps.
